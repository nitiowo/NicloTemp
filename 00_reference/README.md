# 00_reference

Reference genome information for the two study species.

Genome FASTA and GTF files are stored in `Data/reference_data/` (not tracked by git — too large).

| Species | Assembly | Source |
|---------|----------|--------|
| *Bulinus truncatus* | GCA_021962125.1 | NCBI GenBank |
| *Schistosoma haematobium* | GCF_000699445.3 | NCBI RefSeq |

The combined (species-prefixed) genome used for alignment is built by `02_alignment/prefix_combine.sh`.
